# Commands and flags

Generated by `scripts/reference.mjs` from `lib/erlang.js`, `package.json`, `scripts/trace.sh` and `scripts/load.sh`.

## The command

The usage line, as the command prints it:

```text
usage: erlang <dir> [--out <file>]   |   erlang --version
```

| Argument | Meaning |
| --- | --- |
| `<dir>` | The directory scanned. Required unless --version is given. |
| `--out <file>` | Where the report is written. Before or after <dir>. |
| `--version, -v` | Alone, prints one version line and exits 0. |

Any other argument starting with - is bad usage: the usage line is printed on stderr and the exit code is 64. This includes --help.

The version line has this form:

```text
erlang <version> (commit <commit>): load and resilience checks (not the Erlang runtime)
```

Without `--out`, the report is written inside the Erlang directory at the path `join(ROOT, 'dist', 'reports', basename(resolve(dir)) || 'root', 'report.json')`, that is `dist/reports/<name of dir>/report.json`.

## Harnesses

### `scripts/trace.sh`

Usage: scripts/trace.sh [--load] [form ...] a form is e.g. L01a-n-plus-one/sql; with none, every fixtures/<id>/<form>/trace/ trace.json. --load runs the load harness instead (scripts/load.sh, research/load-harness.md) on each form's load/load.json, with k6.

Exit codes: 0 every form as expected; 1 a form was not; 2 cannot run (Docker, or Postgres did not start); 64 bad usage; 75 ITTEN's timing lock stayed active past the wait (ERLANG_LOCK_WAIT_S, 600 s by default).

### `scripts/load.sh`

Usage: scripts/load.sh form ... e.g. scripts/load.sh L12-no-load-shedding

Exit codes: as scripts/trace.sh; 2 also when k6 is missing or a step is over its caps.
