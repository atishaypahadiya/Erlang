# Exit codes

Generated by `scripts/reference.mjs` from `lib/erlang.js`, `lib/crash.js` and `bin/erlang.js`.

These are the codes of `erlang <dir>`. A finding fails a run when its severity is `error` or `warning`; `info` never does.

| Code | Meaning | Source |
| --- | --- | --- |
| 0 | The report is complete and no finding is an error or a warning. | lib/erlang.js, exitCode |
| 1 | At least one finding is an error or a warning, whatever the status. | lib/erlang.js, exitCode |
| 2 | The report is refused. | lib/erlang.js, exitCode |
| 3 | The report is partial and no finding is an error or a warning. | lib/erlang.js, exitCode |
| 64 | The arguments are not a usage the command accepts. | lib/erlang.js, main |
| 70 | An internal failure: an uncaught exception or rejection, or a module that fails to load. | lib/crash.js, EXIT_INTERNAL; bin/erlang.js |
