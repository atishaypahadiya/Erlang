# Checks and thresholds

Generated by `scripts/reference.mjs` from each check module, in the order of `CHECKS` in `lib/erlang.js`.

The checks run in this order. For each, the rule ids its source names, its strength where the source states one, its named numeric constants and the named sets of forms it recognises.

## `no-timeout`

Source: `checks/no-timeout.js`.

Rules named in the source: TMO-01, TMO-03, TMO-04.

Strength: MUST.

| Constant | Value | Meaning |
| --- | --- | --- |
| `MS` | 10000 | Milliseconds of the timeout or AbortSignal.timeout that an automatic fix writes. |
| `MAX_CALLER_DEPTH` | 3 | Calls followed outward when a fetch signal comes from a parameter; past it the finding is info, unresolved. |
