# Limits

Generated by `scripts/reference.mjs` from `lib/sources.js` and `lib/handlers.js`.

## Files read

- Source files are those whose names match `/\.(?:[cm]?[jt]s|[jt]sx)$/`.
- Directories with these names are not read, wherever they are: `node_modules`, `.git`, `dist`, `build`, `out`, `.next`, `.nuxt`, `.svelte-kit`, `.output`, `.vercel`, `.netlify`, `.astro`, `.turbo`, `.cache`, `coverage`.
- Symbolic links are not followed.
- A file larger than 1048576 bytes is not read, and the report is partial.

## Request handlers found without configuration

| Framework | Forms |
| --- | --- |
| Express | app.get('/path', ...fns) and the other verbs, router.route(...) .get(fn), on express() or express.Router(); a router mounted with app.use('/prefix', router) has the prefix added. |
| Fastify | app.get('/path', [opts,] fn), app.route({ method, url, handler }), on fastify() or on the instance a plugin receives, with the prefix it is registered under. |
| node:http | http.createServer(fn) and https.createServer(opts, fn); no method or route. |
| Next.js | the GET, POST, ... exports of app/**/route.{js,ts}, with the route from the folders; the default export of pages/api/**, with no method. |
